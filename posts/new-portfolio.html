Rebuilding my portfolio in the open

This post is the changelog of my own website. The old portfolio was a single HTML file with a full-page three.js background and everything hardcoded. This rebuild keeps the identity — Syne + Space Mono, terminal labels, dev aesthetic — but changes three things underneath.

What changed

  • Separate pages with a real navbar — home, work, certificates, journal, contact. No more one infinite scroll.
  • Content lives in one file — js/data.js holds every repo, certificate and post. Updating the site never means wrestling markup.
  • Live GitHub stats — stars and forks are fetched from the GitHub API at view time, so the numbers on this site stop lying as soon as I merge something.

Constraints I set

  • No build step. Deploy = push. Anyone can clone and open index.html.
  • Everything must degrade: no WebGL hero if three.js fails to load, "—" placeholders if the GitHub API rate-limits, single static frame if the visitor prefers reduced motion.
  • Monospace is the voice, not the body — long paragraphs stay readable.

What ships next

The certificates page is live but waiting for my badges, the journal will carry project announcements before they hit GitHub, and there is a Soroban automation tool in the making — first details will drop here first. Follow along.

— Aditya
